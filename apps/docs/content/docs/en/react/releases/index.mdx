## Latest Release

### v1.4.0

**August 28, 2026**

Keyboard focus rings now render. Two selectors could never match — `:focus-visible:not(:focus)`, which is unsatisfiable, and `:focus-visible` on the Checkbox, Switch and Radio roots, which are `<label>` elements that never receive focus. Across thirty-one stylesheets the package ring appeared only when React was driving the component. A visual change on keyboard focus; pointer interaction is unchanged.

## Release Schedule

BlakeUI follows a regular release cycle:

- **Patch releases**: Bug fixes and minor improvements as needed
- **Minor releases**: New components and features, typically monthly
- **Major releases**: Architectural changes with migration guides
