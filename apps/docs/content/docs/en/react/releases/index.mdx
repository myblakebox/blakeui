## Latest Release

### v1.3.0

**August 22, 2026**

Body-role text now ships at font-weight 450 instead of the browser-default 400 — a real value on Figtree's variable axis. Paragraphs, table cells, captions and form values render slightly heavier; headings, buttons, labels and other deliberate weights are untouched. A visual change: screenshot baselines will differ.

## Release Schedule

BlakeUI follows a regular release cycle:

- **Patch releases**: Bug fixes and minor improvements as needed
- **Minor releases**: New components and features, typically monthly
- **Major releases**: Architectural changes with migration guides
