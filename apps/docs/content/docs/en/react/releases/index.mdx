## Latest Release

### v1.2.0

**August 20, 2026**

The dark-theme focus ring no longer aliases the accent and now clears WCAG 1.4.11 on every surface it lands on. Reduced motion is gentler rather than harsher across 50 component stylesheets: movement is suppressed while colour and opacity transitions keep running.

## Release Schedule

BlakeUI follows a regular release cycle:

- **Patch releases**: Bug fixes and minor improvements as needed
- **Minor releases**: New components and features, typically monthly
- **Major releases**: Architectural changes with migration guides
